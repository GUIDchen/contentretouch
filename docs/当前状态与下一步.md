## 四、几条反复验证过的做法（接手时请沿用）

1. **先量事实，再改**；量不出收益就退（§217/§288/§289）；
2. **口径决定结论**：整图 vs 产品同口径（脸裁剪）会把结论翻过来（§266）；计数不等于数值（§224）；
3. **运行期问题必须用探针量中间量**，读码只能提出假设（§278 到 §283 四连败）；
4. **测试不能依赖开发机状态**（§270/§286/§287）；
5. **「能力在、没接上」是本项目最常见缺口**（已 5 次：鼻解析、耳解析、LaMa、智能消除按钮、refineMaskWithSAM）——
   接手时先查「内核已有但界面没接」的能力，收益通常最快。

## 十、模型管理用法（9.10.86 上线）

位置：右侧栏「挑图」面板 → 资源区。两组：精细分割（SAM）与生成式修复（LaMa）。

### 10.1 两个开关的分工（正交，别混）

| 控件 | 管什么 | 默认 |
|------|--------|------|
| 组标题下的那个大 Toggle | **用不用**这个功能（samPreferred / laMaPreferred） | SAM 开、LaMa 关 |
| 列表里每个候选的 Toggle | **用哪个**候选（注册表 enabled，同槽位互斥） | 新登记的一律关 |

⇒ 关掉大开关 = 整个功能不参与；打开大开关但列表里没启用项 = 回退到旧的固定目录。

### 10.2 增删与登记（三步）

```
1) 增：把模型目录/包放到
     ~/Library/Application Support/ContentRetouch/Models/LaMa/<名字>/
   （或 .../Models/SAM/<名字>/）—— 也可以直接用面板上的下载按钮
2) 登记：点 [把已装模型登记进列表] ⇒ 扫描该目录并写进 models.json（幂等 ✓）
   提示「新登记 N 个」；列表里随即出现该候选
3) 选用：在列表里打开它的 Toggle（同槽位会自动关掉另一个 ✓）
   减：列表里点 [删除] 只从列表移除；磁盘文件仍用原来的删除按钮
```

### 10.3 两个默认值的依据（都量过）

```
SAM    默认开：同掩膜区覆盖为单点的 6.0 到 9.5 倍（§345/§358）
```
