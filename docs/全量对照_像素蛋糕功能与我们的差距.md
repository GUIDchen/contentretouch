# 全量对照：像素蛋糕功能 vs 我们的实现（含偏差与可行性判断）

> 这份表是「哪些还没实现 / 有没有偏差 / 能不能加」的清单。判据分三档：
> **已实现**（能跑并实测过）/ **可近似**（Vision + Core Image 能做可用级，达不到它的水平）/ **做不到**（需要训练好的生成式或分割模型，本机没有推理框架也没有数据）。

## 一、人像美化（它有 13 个子模块）

| 它的功能 | 我们的状态 | 判据 | 说明 |
| --- | --- | --- | --- |
| 页面概述 / 人物属性栏 | **部分** | 可近似 | 属性栏（女/男/儿童/长辈女/长辈男）与单人/所有人已做进界面；**但属性目前只是标签，没有真的按属性换参数**（它背后是按人群训练的不同模型） |
| 祛除瑕疵（12 条：祛斑祛痘/祛痣/祛油光/祛汗珠/黑眼圈/眼袋/鼻孔瑕疵/唇纹/双下巴/下颌线…） | **未做** | 可近似（粗） | 做法：皮肤掩膜内做高通斑点检测 → 用「模糊填充」当修补。**能做到「斑淡了」，做不到「像没长过」**（真 inpainting 需要模型） |
| 皮肤调整（磨皮/质感/肤色统一） | **部分** | 已实现（柔化级） | 磨皮三档已实测（脸内高频 -26% / -54%）；**肤色统一只是近似**（±1 级，等于没做）；「保毛孔」的质感磨皮需要自定义 CIKernel |
| 面部重塑 / 3D 塑颜 | **未做** | 可近似（粗） | 有 Vision 108 点关键点 + Core Image 的 Bump/Pinch 扭曲滤镜，可做「局部推拉」级；**没有 3DMM，转头角度大时会露馅** |
| 表情管理（微笑/睁眼） | **未做** | 做不到 | 抬嘴角要重绘牙齿与皮肤 → 生成式 |
| 牙齿美化 | **未做** | 可近似 | 唇部关键点 + 局部美白/去黄，能到可用级 |
| 眼睛增强（眼神光/黑白眼珠） | **未做** | 可近似 | 眼部关键点 + 局部对比/提亮 |
| 妆容调整 | **未做** | 可近似（很粗） | 唇色/腮红可以按关键点做颜色叠加；自然度远不如它 |
| 头发调整（发际线/发量） | **未做** | 做不到 | 发量填充是生成式 |
| 手部美化 / 脚部美化 | **未做** | 可近似（很粗） | 无专门关键点，只能靠分割近似 |
| 全身美型（天鹅颈/直角肩/身型） | **未做** | 可近似（粗） | Vision 有**人体姿态**关键点（肩/肘/髋/膝），可做分段变形 |

## 三、偏差（我们偏离计划的地方）

1. **M5 曾出现「假绿灯」**：磨皮第一版在脸区产生暗块，却因为我取样在脸区外而误判为成功。已修正并写进文档。教训：视觉验证必须按检出的人脸矩形取样。
2. **肤色统一名不副实**：目前只是 ±1 级的近似，不算实现。
3. **人物属性只是标签**：像素蛋糕的属性背后是不同的人群模型，我们目前不按属性换参数。
4. **打包分发没做**：DMG/签名/更新清单仍未做（上一轮预算被 M5 与 bug 占用）。
5. **色彩管理曾报过一次误警**（根因是我自己三行放错位置），已在文档更正。

## 四、结论：能不能「把所有功能加上」

**不能**——而且我不想用「已加上」来含糊过去。原因是硬的：

- 它的一半功能（创成式填充、换装、换天、拉龄、加腹肌、闭眼修复、宠物美化、发量、表情管理）是**生成式模型**，本机既没有推理框架（无 PyTorch/ONNX/CoreML 模型），也没有训练数据；
- 另一半（祛斑、重塑、牙齿、眼睛、手部、背景、衣物）可以用 Vision 关键点 + Core Image 做到**可用级近似**，但达不到它的成熟度——它是靠数据与模型堆出来的，不是靠工程技巧。

**能做的、值得做的（按性价比排序）**：

| 序 | 功能 | 预估 | 为什么值得 |
| --- | --- | --- | --- |
| 1 | 界面「皮肤」面板（磨皮分档 + 肤色开关） | 小 | 核心已完成，只差接线，等于白捡 |
| 2 | AI 挑图（质量分 + 清晰度排序） | 小 | 婚礼交付最省时间的功能，数据现成 |
| 3 | 裁剪旋转 / 祛黑白边 | 小 | 纯几何，简单且天天要用 |
| 4 | 背景纯化（人像分割 + 低频 flatten） | 中 | 分割已实测可用 |
| 5 | 牙齿美白 + 眼睛增强 | 中 | 关键点已有，效果直观 |
| 6 | 液化（Bump/Pinch 近似） | 中 | 影楼刚需，近似版就有用 |
| 7 | 祛斑（高通检测 + 模糊填充） | 中 | 「斑淡了」有价值 |
| 8 | 历史记录与回滚 | 中 | 批量修图的安全网 |
| 9 | 打包分发（DMG + 签名 + 更新） | 中 | 让它成为能交付的软件 |

**明确不做的**：生成式那一整块（换装/换天/创成式填充/拉龄/闭眼修复/加腹肌）、宠物美化、云协同与 ERP。
