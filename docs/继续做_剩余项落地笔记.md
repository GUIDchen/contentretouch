# 继续做：剩余项的落地笔记（3~9）

> 进度：1 皮肤面板 ✅ / 2 挑图面板 ✅（本轮完成，核心与界面都已接）。下面是 3~9 的具体做法，
> 写清楚是为了下一轮能直接开工，不用重新调研。

## 3. 裁剪旋转 / 祛黑白边

- Core Image 纯几何：`transformed(by:)` + `cropped(to:)`；拉直用旋转角；祛黑白边 = 检测四边连续黑/白列并裁掉。
- 界面：左工具条加「裁剪」进入裁剪模式（画布上拖拽手柄）。
- 验收：给一张带白边的扫描件，自动裁掉且不切到内容。

## 4. 背景纯化

- `VNGeneratePersonSegmentationRequest`（已实测：192×256 蒙版，0.15 s 预热后）拿人像蒙版；
- 背景 = 1 − 人像蒙版；在背景内做**低频 flatten**（大半径高斯做低频，替换成低频 → 去掉褶皱与脏点），再做一次轻度降噪；
- 可选「背景提亮/压暗」滑杆（证件照与白棚常用）。
- 验收：纯色背景的褶皱被压平、人物边缘无白边。

## 5. 牙齿美白 + 眼睛增强

- `VNDetectFaceLandmarksRequest` 已经有：innerLips（牙齿所在区域）、左/右眼（眼珠与眼白）；
- 牙齿：唇内区域做「降饱和 + 提亮 + 去黄」；眼睛：眼白提亮、瞳孔加深、加一个眼神光点；
- 蒙版都用关键点生成的多边形羽化蒙版（复用 `faceMask` 的思路，改成长椭圆/多边形）。
- 验收：脸内取样，牙齿区域 b 通道上升、饱和度下降；眼睛区域对比上升，画面其他部分不变。

## 6. 液化（近似）

- Core Image 自带 `CIBumpDistortion` / `CIPinchDistortion` / `CIVortexDistortion`——这就是「膨胀/收缩/旋转」；
- 笔刷落点 → 以该点为中心的失真滤镜 + 半径 + 强度；`CITwirlDistortion` 可当旋转；
- 局限：**不是网格变形**，没法做「向前变形」那种自由推拉；冻结/重建也做不了。
- 验收：对着手臂做膨胀，只有笔刷半径内变形、边缘过渡自然。

## 7. 祛斑（近似）

- 皮肤掩膜内做**高通检测**：高半径高斯 vs 原图差分 → 阈值 → 得到斑点蒙版（暗斑再叠一个颜色先验）；
- 修补用「蒙版内混合强模糊图」当 inpainting 的替代（和磨皮同一套机制，只是半径更大、强度更高）；
- **诚实边界**：结果是「斑淡了」，不是「像没长过」；真 inpainting 需要模型。
- 验收：给一张有明显痘印的图，斑区域的局部对比下降，脸以外不动。

## 8. 历史记录与回滚

- 每次出图把参数写进 sidecar（`<out>.params.json`，已有报告 JSON 可复用）+ 原图永不覆盖；
- 界面「历史」面板列出「时间 / 参数摘要 / 误差」，点一条即回到那版参数重渲；
- 批量同样落盘，支持「只重跑失败项」。

## 9. 打包分发

- ContentRetouch 打 DMG：复用 `tools/dist/` 里已有的 `sign_and_notarize.sh` 与 `make_update_manifest.mjs`（现在是给 ContentHarvester 用的）；
- 无证书时：ad-hoc 签名 + 说明「首次打开需右键→打开」；
- 更新清单：`latest.json` + minisign 签名（key 已存在 `~/.tauri/harvester.key`）。
