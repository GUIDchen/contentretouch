# 交付说明（M1 收尾）

> 一句话：这是一款 macOS 端「多平台内容收集器」——登录你自己的账号，选择式下载图片与视频、把作品信息落进本地库、按模板保存并转换格式。M0 阶段先跑通了抖音收藏（1272 条 / 12269 张图的实战），M1 把它做成了有界面的 App。

## 3. 环境依赖

| 依赖 | 用途 | 缺失时的表现 |
| --- | --- | --- |
| Node 22.5+ | 所有采集/下载/入库/转换脚本（用到 node:sqlite） | 入库会明确提示版本不足 |
| Google Chrome / Chromium / Edge | 提供可扫码登录的会话 | 会话模块提示找不到浏览器 |
| ImageMagick（magick） | 图片格式转换 | convert 退出码 3 并提示 brew install imagemagick |
| ffmpeg | 视频抽音轨 | 同上 |
| Rust 1.9x + Tauri CLI | 构建 App | 源码仍可用脚本形态运行 |

## 4. 快速开始

    # 1) 装依赖（macOS）
    brew install node imagemagick ffmpeg

    # 2) 起一个专用浏览器并扫码登录（会话与日常浏览器隔离）
    /Applications/Google\\ Chrome.app/Contents/MacOS/Google\\ Chrome \\
      --remote-debugging-port=9222 --user-data-dir="$HOME/.dsh/douyin-profile" \\
      --disable-backgrounding-occluded-windows --disable-renderer-backgrounding \\
      https://www.douyin.com/

    # 3) 一条命令跑通全流程（端到端演练，可反复执行）
    sh tools/e2e_drill.sh

    # 4) 启动 App（开发态）
    cd app && pnpm tauri dev

## 6. 必须知道的三个限制

1. **M0 的覆盖率要更正**：当时报的「1272 / 1272 = 100%」只对那份清单成立。收藏页现在必须显式点一次「收藏」标签才会继续加载，旧采集脚本没点，实际收藏还有 993 条没进清单。修正后的口径是：真实收藏约 2019 条（含收藏夹共约 2265），M0 覆盖约 56%。多出来的部分已经在清单里，勾选下载即可。
2. **历史条目作者字段缺失**：M0 的作者提取取到过导航栏文字「我的」，本轮已清洗，但历史 2264 条的作者需要重下或专门补采（新下载会自动回填）。
3. **签名与公证未做**：本机没有 Developer ID 证书，当前包是 adhoc 签名，只在你自己机器上右键打开可用；对外分发需要证书，步骤见 docs/分发与签名指南.md。
