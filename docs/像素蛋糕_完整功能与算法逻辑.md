## 二、人像美化（13 个子模块，实测+手册）

手册给出的完整子模块：**页面概述 / 人物属性栏 / 祛除瑕疵 / 皮肤调整 / 面部重塑 / 表情管理 / 牙齿美化 /
眼睛增强 / 妆容调整 / 头发调整 / 手部美化 / 脚部美化 / 全身美型**（「含祛除瑕疵、皮肤调整等 10 余项模块」）。

**人物属性栏**（实测）：「女 / 男 / 儿童 / 长辈女 / 长辈男」5 种属性 + 「单人 / 所有人 / 部分人联动」作用范围 + 可改人物年龄性别。
这层的意义：**同一张片子里的不同人给不同参数**，是影楼流水线的刚需。

**其余子模块（手册）**：皮肤调整（肤色统一、质感磨皮/中性灰、肤质）；面部重塑（脸型、五官、3D 塑颜）；
表情管理（微笑/睁眼等）；牙齿美化（美白/修复破损）；眼睛增强（眼神光/黑白眼珠）；妆容调整（主题妆容）；
头发调整（发际线/发量/毛躁）；手部美化；脚部美化；全身美型（天鹅颈/直角肩/身型）。

### 这些功能背后的算法（推断，按难度分层）

1. **皮肤掩膜**：人脸解析网络（face parsing）输出皮肤/眉毛/眼睛/嘴唇分区；或关键点 + 肤色聚类。这是所有磨皮类功能的地基。
2. **磨皮**：两条主流路线——① 保边平滑（双边滤波/导向滤波/表面模糊）② **频域分离**（低频做颜色统一、高频做质感保留，也就是「中性灰」的手工思路自动化）。它宣传的「像素级中性灰磨皮 + 高清 AI 网格 + 保留皮肤质感」基本可以对应到「多层频域分离 + 纹理合成」。
3. **祛瑕疵**：斑点检测（LoG/高通+阈值）+ **inpainting**（PatchMatch / Criminisi / 或训练好的修复网络）。近两年版权方普遍换成「检测网络 + 修复网络」端到端。
4. **面部重塑 / 3D 塑颜**：106 点关键点或 **3DMM 拟合**（3D 人脸形变模型）→ 用 **MLS（移动最小二乘）或 TPS（薄板样条）** 做网格变形；3D 版的意义是「转头角度变化时形变仍自然」。
5. **表情管理**：关键点驱动 + 局部生成式修补（把嘴角抬起来需要重绘牙齿/皮肤）。
6. **牙齿/眼睛/妆容**：区域检测 + 颜色映射（色相偏移、亮度提升、饱和度调整）+ 必要时生成式重绘。
7. **全身美型**：人体关键点（肩/颈/腰/腿）+ 分段网格变形，比人脸难在「身体轮廓没有稳定的关键点」。

## 三、其它模块（实测 + 手册）

**衣物美化（实测逐条）**：衣服祛褶皱 New（上衣 / 下装 / 祛细褶皱 / 祛粗褶皱）、衣服祛瑕疵、衣服祛汗渍 New·Beta（带「编辑衣服汗渍蒙版范围」）、衣服边缘平整，底部一个 **AI 衣服精修** 大按钮。
  - 算法推断：高频方向性滤波抑制褶皱纹理 + 低频光照平滑；汗渍=局部暗斑检测 + 提亮去饱和；两者都要求先做**衣服区域分割**（否则会伤皮肤）。

**图像美化 / 背景**（手册+官网）：纯色背景褶皱/划痕/脏点去除、全景分割抠图、换背景、换天空、边缘优化、祛边。
  - 算法推断：**全景分割**（Mask2Former 类）出人/物/背景 → 背景纯化用低频重建（把褶皱当低频不均一做 flatten）→ 换背景/天空用分割掩膜 + 边缘羽化 + 色彩匹配。

**色彩调节 / 预设**（手册+实测）：16bit AI Raw 引擎、100+ 调色工具、ProPhoto 色空间、0 延迟实时预览、AI 色彩风格（婚纱/婚礼跟拍/晨光/简白/清新/自然）、**AI 追色（样片→客片，含局部追色）**、预设管理（新建/导入/管理，推荐/我的）。
  - 算法推断：AI 追色 = 参考图与目标图的**颜色分布迁移**（Reinhard 统计迁移 / 3D LUT 回归 / 神经网络风格迁移），局部追色 = 分割后的区域级匹配。**这一项与我们已有的管线思路完全一致**，只是他们做得更细。

**裁剪旋转**：裁剪、旋转、校正、水平/垂直校正、自由变换、还原。

**手动工具（手册原文，已抄全）**：
  - **手动液化**（快捷键 N）：工具 = 向前变形 / 重建 / 平滑 / 旋转 / 褶皱 / 膨胀 / 左推 / 冻结 / 解冻；参数 = 大小 / 密度 / 压力 / 速率 / 固定边缘 / 显示蒙版。
  - 手动修复、手动涂抹画笔、参考线、祛除黑白边。
  - 算法推断：液化是**网格变形 + 高斯衰减权重**（笔刷落点周围的位移场），冻结 = 蒙版不参与变形，重建 = 按原始坐标插值回退。

**AI 点修（手册）**：点选/一句话驱动的局部修图（例如点眼角 → 自动祛眼袋）。算法推断：分割/检测 + 指令解析（LLM）+ 局部修复模型。
**AI 挑图（手册）**：按清晰度/闭眼/表情/构图打分筛选。算法推断：人脸质量模型（清晰度 + 睁眼 + 表情）+ 审美打分。
**AI 工具箱 / 创意模块（官网+实测）**：创成式填充、AI 补光、换天气、老照片修复、AI 拉龄人、AI 面部重绘、证件照换装、AI 瘦肚子、AI 加腹肌、闭眼修复、形体液化 2.0 —— **消耗积分**，首次用需同意协议（AI 生成内容默认带标识）。算法推断：扩散模型（他们自研，官网底部公开了「真景大模型备案号」与「算法备案号」）。
**批量 / 交付（手册）**：创建虚拟副本（同图多版本）、**批量应用效果至其他图片**、导出图片设置、联机拍摄、云协同、在线选片交付、对接 ERP。
  - 这层的意义：影楼要的从来不是「修一张」，而是「拍 500 张、修 500 张、交付 500 张」。

## 五、对我们设计的三条硬结论

1. **它的功能面很宽，但骨架极简单**：左工具、中画布、右「窄栏模块 + 宽栏参数」、底部批量条。我们照这个骨架做，功能按 M1-M5 逐步填。
2. **模块化的关键是「人物属性 + 作用范围 + 功能组 + 滑杆」四层参数模型**：抄这一层，后面加任何功能都只是往组里加滑杆。
3. **我们真正的差异化在「参考库」**：它给你官方预设，我们可以给你**从你自己 13,484 张收藏里长出来的风格**，并且能回答「这张客片最像你收藏里的哪几张」。
