# 像素蛋糕：功能与布局实测（本机 10.0.0）

> 目的：在动手做我们自己的 App 之前，把它真机跑起来看清楚——它到底有哪些功能、界面怎么组织、
> 哪些是「一键」、哪些是「滑杆」、哪些是「AI 工具箱」。以下全部是**本机实机观察**，不是官网转述。

## 0. 本次调用情况

- 运行来源：挂载卷 /Volumes/像素蛋糕-10.0.0-769_arm64（**10.0.0**，arm64 原生；/Applications 里那份是 9.0.0）。
- 窗口：**1641 × 923 pt**，位置 (684, 517)；已登录（本次会话有效），打开着一张婚礼照（中式礼服新人）。
- 观察手段：screencapture 截图 + System Events 点击驱动（辅助功能权限可用）。
- 截图存档：docs/shots/（精修主界面 / 人像美化面板 / 创意AI工具箱 / 图库）。
- **我明确没做**：没替用户登录、没点「同意用户协议」、没点「隐藏 AI 水印」授权——这些是需要你本人确认的操作。

## 1. 顶栏：三个模块 + 导出

    左：窗口控制           中：图库 | 精修 | 创意(NEW)          右：会员续费状态 · 导出（高亮主按钮）

- **图库**：项目内图片管理；**精修**：主编辑工作区；**创意**：AI 工具箱（消耗积分）。
- 导出是全局主操作，常驻右上角（黄色高亮），点开才是导出设置（格式/尺寸/水印等）。
- 会员状态常驻（续费入口），说明它是订阅/积分的商业模式。

## 2. 精修工作区布局（核心）

     ┌ 左竖排工具条 ┬──────── 画布（可缩放/抓手） ────────┬ 分类图标列 ┬ 参数面板 ┐
    
- **左竖排工具条**（从上到下，实测名称）：缩放 23%▾ / 合适 / 抓手 / 祛斑 / 参考线 / 液化 / 污点修复 Free / 修补 Free / 仿制图章 Free / 智能消除 / AI点修 / 重置效果。
  - Free 标记 = 免费工具，未标记的多半走会员/积分；
  - **重置效果**单独一个入口，位置在工具条末端——随时可回退。
- **中间画布**：缩放百分比直接在工具条顶部可选（23% → 合适）。
- **右侧是双栏**：
  - 第一列（窄，图标）：**人像 / 衣物 / 动物 / 背景 / 后调色 / 裁剪 / 历史 / 联机 / 自定义**——这是「修什么」的一级分类；
  - 第二列（宽，参数）：**预设 | 人像美化** 两个大页签 + 具体滑杆。

## 3. 参数面板怎么组织（人像美化实测）

从上到下的层级非常清晰，这是它最好抄的一点：

    人物类型： 女 | 男 | 儿童 | 长辈女      ← 不同人群默认参数不同
    作用范围： 长辈男 | 单人 | 所有人      ← 一张图里多个人时，选对谁生效
    功能分组： 祛除瑕疵 | 皮肤调整 | 面部重塑 | 表情管理   ← 可搜索
    组内滑杆： 面部祛瑕疵 0 / 祛斑祛痣 0 / 祛痣 0 / 祛油光（脸部） 0 /
               祛汗珠（脸部）🤖 / 祛黑眼圈 / 祛眼袋 / 祛鼻孔瑕疵 🤖 / 皱纹修复 / 祛双下巴 🤖

- 每个滑杆：**0–100 的归一化值**，右侧有 ↺ 单条复位；
- **🤖 标记 = AI 驱动**（祛汗珠、祛鼻孔瑕疵、祛双下巴），其余是传统算法；
- 「皮肤调整 / 面部重塑 / 表情管理」是并列的功能组，结构与「祛除瑕疵」一致——**同一套滑杆外壳**装不同的算法；
- 「人物类型 + 作用范围」两级选择是**面向商业交付**的设计：影楼一次拍一堆人，需要按人群批量给参数。

## 4. 预设系统（实测清单）

    [预设] 页签 → 推荐 | 我的        ← 官方推荐与自存预设
                 全部预设 ▾          ← 下拉筛选
                 无效果 / 肤质肤色 / 胶片 / 婚纱 / 婚礼跟拍 / 儿童 / 新生儿 / 孕妇 /
                 全家福 / 写真 / 旅拍 / 毕业·证件照

- **按拍摄场景分类**（不是按「风格名」），这是它的用户体验关键：摄影师打开就知道点哪个；
- 「酒店婚礼跟拍」这类细分类目和我们的参考库聚类可以对上——我们的 6 类风格可以映射进这些类目；
- 预设是「一键套用」，滑杆是「手动精调」，两者共用一个参数模型。

## 5. 创意模块（AI 工具箱）

- 打开即「欢迎来到创意模块」说明 + 合规准则：
  - 含 **AI拉龄人 / AI面部重绘 / 证件照换服装** 等 AI 工具与画图修图能力；
  - **使用 AI 功能会消耗积分**（活动领取或付费）；
  - 生成内容应用回原图精修后再导出不重复扣次数；
  - 异常行为在导出时按规则扣积分。
- 工具以**缩略图网格**呈现（可见：AI 拾色人 / AI 面部重绘 / 闭眼修复 / AI 瘦肚子 / AI 加腹肌 / 形体液化 2.0 …），分页「1/5」+ 新手引导；
- 分类：探索更多 / 多场景 / 工具；右上角有 **导出到本地 / 应用至精修** 两个动作；
- 首次使用 AI 生成会弹「隐藏 AI 生成水印」，需同意用户协议才可隐藏——**合规设计**：AI 生成内容默认带标识。

## 6. 图库模块

- 网格视图 + 每张缩略图带**星级评分**；顶部：`显示状态` / `全效果模式` 两个开关 + `批量删除`；
- 首次进入有气泡提示：「当前为原图模式，点击即可切换为全效果模式」——
  即**原图 / 效果预览一键切换**（大图预览时能立刻看修与不修的区别）。

## 7. 工程与实现观察（从进程与包结构看）

- Qt5 + QML/QtQuick 壳 + 内嵌 QtWebEngine(Chromium) + QCefView；主程序 174 MB，**独立 pix-worker 进程 132 MB** 扛重活；
- Frameworks 里**没有独立推理 dylib**（无 onnxruntime/mnn/ncnn/torch）→ 推理与模型静态链接在二进制里；
- Resources/effect 255 MB（效果/素材/模型资源）；
- Sentry 崩溃上报（sentry-o566200.pixcakeai.com），本地配置目录 `~/Library/Application Support/PixCake-qt_pro/`；
- 挂载 DMG 直接运行：它的分发形态是 DMG + 内置更新，和我们的 Tauri 包一致。

## 8. 对我们 App 的直接启示（对照表）

| 它的做法 | 我们照做的部分 | 我们要改的部分 |
| --- | --- | --- |
| 顶栏三模块：图库 / 精修 / 创意 | 保留同样的三段结构 | 我们的「图库」就是参考图库 + 项目，「创意」先不做（需要生成式模型） |
| 左竖排工具条 + 右上常驻导出 | 照做：工具条 + 常驻导出 | 我们第一阶段只放：缩放/抓手/参考线 + 对比（原图↔效果） |
| 右侧双栏：分类图标 + 参数面板 | 照做：左窄列放「人像 / 色彩 / 背景 / 历史」，右宽列放滑杆组 | 我们的右列顶部改为 **参考组选择 + 预设** |
| 参数组织：人物类型 → 作用范围 → 功能组 → 滑杆(0-100, ↺) | **完全照做**，这是最值得抄的一层 | 我们的滑杆在「风格项」上由参考图计算自动填值 |
| 🤖 标记 AI 功能；Free 标记免费 | 照做标记体系 | 我们标「本图自适应」与「来自参考图」两种来源 |
| 预设按拍摄场景分类 | 照做：把 6 类风格映射到「婚礼晨光 / 婚礼跟拍 / 日系清透 / 暗调暖 / 雾面 / 高饱和」 | 我们的预设**可以由你自己的库继续长出来** |
| 原图 / 全效果一键切换 | 照做 | 再加「前后对比滑杆」（拖动分割线） |
| 积分制的 AI 工具箱 | 不做 | 我们没有云端算力与积分体系；对应能力用系统框架尽量靠近 |

## 9. 结论（对我们最重要的三条）

1. **它的价值不在功能数量，而在参数与场景的映射**：同一套滑杆外壳，配上「人物类型 + 场景预设 + 一键套用」，让影楼流水线能用起来。我们要抄的是这个骨架，不是它那 100+ 个功能。
2. **它的护城河是 AI 模型（磨皮/祛瑕/重塑）**：这部分我们用系统框架只能做到「可用」，方案里已经如实标出。
3. **它的交互范式很朴素**：左工具、中画布、右参数、上导出，没有任何花哨——我们的 SwiftUI 原型已经是这个形状，继续按这个骨架长即可。
