# M5 皮肤处理（第一刀 + 修正记录）

> ⚠️ 重要修正：**最初的频域分离实现是坏的**——它在脸区会生成暗块（实测 R 199 → 48）。
> 我一开始量的是脸区**外面**的取样，所以只看到「轻微变柔」，没发现脸已经毁了。
> 后来按 Vision 检出的人脸矩形（155x155+307+341）裁出来看，立刻暴露。
> 现在改成「按蒙版把模糊图混回原图」的正确做法，并重新实测（见下）。

## 修正后的实现

    smoothSkin = CIBlendWithMask(高斯模糊图, 原图, 蒙版 × (1-keep))
    keep = (1 - 强度/100)^1.6     ← 非线性，中高段更有力

为什么换掉频域分离：Core Image 的 `CISubtractBlendMode` + bias 组合出来的「低频 + 高频×keep」
在脸区不是接近原图，而是明显变暗——这套 blend mode 不能当频域分离用。
真要做质感保留需要自定义 CIKernel（Metal 着色器），这是以后的事。
代价说清楚：现在是**柔化**，不是「磨皮但保毛孔」；毛孔确实会被抹掉一些。

## 实测（脸 1 内缩取样区 110x110+330+365）

| 档位 | 强度 | 脸内高频能量 | 颜色（R/B） |
| --- | --- | --- | --- |
| 关 | 0 | 401.4 | 199.0 / 190.2 |
| 轻 light | 30 | 298.1（**-26%**） | 199.1 / 189.1 |
| 重 strong | 80 | 185.8（**-54%**） | 198.6 / 188.7 |

目视：轻档皮肤略柔、五官清晰；重档皮肤明显细腻，而**眼睛、嘴唇、麦克风纹理、发丝都还在**（因为磨皮只在脸区蒙版内）。
颜色三档基本一致 → 没有引入偏色（原来那版变暗块的问题已消失）。

## 肤色统一（近似，效果很小）

`--skin-tone` 用参考组的高光暖冷当代理，把脸区往参考组方向推。
实测这一档（参考组 warmHi≈4）只带来 **±1 级**的变化，肉眼与数字都看不出来。
**诚实结论：这不算真正的肤色统一**。真正要做的是「参考组肤色均值 → 目标肤色」的颜色迁移，需要用肤色掩膜统计 + 迁移，还没实现。

## 命令行

    retouch-cli --skin-grade light|medium|strong   # 轻/中/重 = 30/55/80
    retouch-cli --smooth 0~100                     # 或直接给数
    retouch-cli --skin-tone                        # 肤色向参考组靠拢（近似，效果很小）

默认关。
