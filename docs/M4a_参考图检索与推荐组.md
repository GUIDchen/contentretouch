## 2. 新工具：recommend

    tools/style/recommend.swift  →  tools/style/recommend

用法：

    ./tools/style/recommend style_out/style_index.jsonl <待修图> \\
        [--groups 3] [--per-group 8] [--json out.json] [--montage <dir>]

**为什么按「作品」聚组，而不是给十张散图**：一场拍摄里的片子风格一致，聚组后用户看到的是
「三个可参考的成片组」，点一组就能拿到那一组整套参数；散图只会让人不知道该参考哪张。
作品 id 直接从文件名取（`0001_7686569319551671433_01.webp` → 第二段就是作品号）。

## 3. 实测（用你的婚片 wedding_01 查）

    查询：wedding_01.jpg　索引 13,484 张　聚出 3 组
      组 1（作品 7417460796675870006）：6 张，最近距离 0.578，组内均值 0.625
      组 2（作品 7678337854469479589）：6 张，最近距离 0.579，组内均值 0.648
      组 3（作品 7682768466080477284）：6 张，最近距离 0.601，组内均值 0.670

**目视验证**（docs/shots/M4_推荐参考组.jpg）：组 1 的首张与你的原片**几乎同款**——
同样是中式婚礼、新娘执礼念稿、新郎侧立、红囍背景；另外两组也是同题材（订婚宴/中式婚礼）的其他作品。

## 4. 与复查结论一致的两点

1. **不给「相似度百分比」**：实测 0.578~0.670 这一区间内既有「几乎同款」，也有「只是同题材」，
   绝对距离在不同题材间不可比；界面按**组**给，并配缩略图，让人自己看。
2. **不做全量风格统计**：推荐出组之后，只对这几张（每组 6 张）现算风格参数即可，
   不需要为 13,484 张都预存影调统计。
